# 🚀 Studio.JS | Modern Freelance Portfolio

A high-performance, responsive portfolio website built with a focus on conversion and clean aesthetics. Designed to showcase development skills and UI/UX expertise.



## ✨ Key Features
* **🌓 Adaptive Dark Mode:** System-aware theme switching with persistent local storage.
* **📱 Fully Responsive:** Optimized for everything from mobile devices to ultra-wide monitors using Tailwind CSS.
* **🎯 High-Converting Hero:** Designed with clear CTAs and "Social Proof" indicators.
* **🧩 Skills Bento Grid:** A modern layout showcasing a diverse technical arsenal.
* **💻 Mac-Style Project Gallery:** Interactive project cards with macOS-inspired window frames.
* **📩 Functional Contact Form:** Built-in validation and simulated submission logic.

## 🛠️ Built With
* **HTML5 & JavaScript (ES6+)**
* **Tailwind CSS** - For utility-first styling.
* **Lucide Icons** - For crisp, consistent iconography.
* **Git/GitHub** - Version control and hosting.
